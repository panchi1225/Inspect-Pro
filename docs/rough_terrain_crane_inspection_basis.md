# ラフタークレーン 作業開始前点検の根拠対応

確認日：2026-10-20（日本時間）。対象：25t・50t共通、各1～15号機。
25t・50tは能力区分であり、メーカー・製品型番を特定しない。
この一覧は全メーカー・全機種の取扱説明書の点検項目を網羅したものではない。
実機の取扱説明書と適用基準、現場条件に従って確認する。

## 法令上の位置付け

★は第78条に直接列挙された機能の作業開始前点検を表す。`isRequired` はこの表示区分のみ。
★のない行も本アプリで確認する14項目に含まれ、未点検のまま保存できない。
2行目の過負荷防止装置の停止機能・設定照合は、条文に直接列挙された過負荷警報装置に対しメーカー資料を踏まえて追加した範囲である。

第78条の日常点検、第77条の月例自主検査、第76条の年次自主検査、第81条以下の性能検査は別の手続である。
本帳票は日常点検の月次集計であり、月例自主検査を代替しない。日常点検に定格荷重による荷重試験を追加しない。
第79条の自主検査記録の3年間保存を、第78条の日常点検記録の法定保存期間とは断定しない。
第80条を踏まえ、異常発見時は使用を中止し、責任者へ報告して直ちに補修その他必要な措置を講じる。
保存は使用許可を意味しない。

## 運用・表示

凡例は「★：クレーン則第78条の作業開始前点検項目」「その他：関連法令・メーカー資料等に基づく追加確認事項」。
14行すべての結果が必要。各行は装備される部分を確認した上で利用者が良・不良を入力する。
非装備の部分が含まれることは、その行の装備部分を未点検で良好にする理由にならない。
本変更では新たな「該当なし」保存状態は作らない。欠けた保存キーは帳票に「未」、記録のない日は空欄とし、非装備を示す記号に変換しない。
一括良好は利用者の明示操作のみ。写真・不良メモは既存と同じ保存形式。
能力区分から荷重の可否を計算しない。作業半径・姿勢・張出幅等に対応する実機の定格荷重表で管理する。
